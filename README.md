# 🍽️ RestoManager - Restaurant Management System

RestoManager, restoran operasyonlarını (masa yönetimi, sipariş takibi, menü yönetimi) dijital ortamda organize etmek amacıyla ASP.NET MVC ve C# kullanılarak geliştirilmiş web tabanlı bir otomasyon projesidir.

## 🚀 Projenin Amacı ve Özellikleri
* **Masa Yönetimi:** Restorandaki masaların doluluk/boşluk durumlarının anlık takibi.
* **Menü ve Ürün İşlemleri:** Yemeklerin, içeceklerin kategorize edilmesi ve fiyat yönetimi.
* **Sipariş Takibi:** Masalardan alınan siparişlerin mutfağa ve kasaya aktarılması.
* **MVC Mimarisi:** Model-View-Controller deseniyle düzenli, sürdürülebilir ve katmanlı yapı.

## 🛠️ Kullanılan Teknolojiler
* **Backend:** C#, .NET Framework / .NET, ASP.NET MVC
* **Veritabanı & ORM:** SQL Server / MySQL, Entity Framework
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap

---

## ⚙️ Kurulum ve Çalıştırma Rehberi (Getting Started)

Projeyi kendi bilgisayarınızda çalıştırmak için:
1. Projeyi bilgisayarınıza klonlayın veya indirin.
2. `RestoManager.sln` dosyasını **Visual Studio 2022** ile açın.
3. Veritabanı bağlantı ayarlarını kontrol edip projeyi **IIS Express** ile çalıştırın.
